# Khaen Complex Center — Khaen Community Web Application
แคนอีสาน: แพลตฟอร์มพิกัดช่างแคน หมอแคน และตลาดเครื่องดนตรีอีสาน

## สถาปัตยกรรมและโครงสร้างโปรเจกต์ (Project Structure)
```
c:\xampp_new\htdocs\sound\
├── schema.sql           # โครงสร้างฐานข้อมูล MySQL และข้อมูลจำลอง (Mock Data)
├── db.php               # ไฟล์เชื่อมต่อฐานข้อมูลด้วย PHP PDO (UTF-8, Prepared Statements)
├── auth_helper.php      # ระบบจำลอง Session Authentication (Mock Admin / User / Google SSO Hook)
├── get_locations.php    # REST API ส่งออกข้อมูล JSON พิกัดหมอแคน/ช่างแคน/ร้านค้า
├── update_location.php  # REST API สำหรับให้ผู้ใช้อัปเดตพิกัด GPS ของตนเอง
├── index.php            # หน้าหลัก (Leaflet.js Map + หมอแคนใกล้ฉัน + Marketplace Grid)
└── README.md            # คู่มือการติดตั้งและใช้งาน
```

## ขั้นตอนการติดตั้งและเริ่มต้นใช้งาน (Quick Setup)

1. **เปิดบริการใน XAMPP:**
   - เปิดโปรแกรม **XAMPP Control Panel** แล้วกด **Start** ที่โมดูล **Apache** และ **MySQL**

2. **นำเข้าฐานข้อมูล MySQL:**
   - รันคำสั่งจากไฟล์ `setup_db.php` หรือนำเข้า `schema.sql` เพื่อสร้างฐานข้อมูล `khaen_community` พร้อม Mock Data ทันที

3. **เข้าใช้งานแอปพลิเคชัน:**
   - เข้าผ่านเว็บเบราว์เซอร์ที่: `http://localhost/sound/`

## ฟีเจอร์หลักในระบบ
- **งานวิจัยเพื่อพัฒนาชุมชนดนตรีอีสาน:**
  - โครงการวิจัยเพื่อพัฒนาชุมชนดนตรีอีสาน โดย **อาจารย์ ดร.สัญชัย ด้วงบุ้ง** อาจารย์ประจำภาควิชาดนตรีศึกษา วิทยาลัยดุริยางคศิลป์ มหาวิทยาลัยมหาสารคาม
- **แผนที่และพิกัด GIS (Leaflet.js):**
  - รองรับการกรอง 3 หมวดหมู่ (ช่างทำแคน, หมอแคน, ร้านขายแคน)
  - ฟังก์ชัน **"หมอแคนใกล้ฉัน (Near Me)"** ค้นหาพิกัดผู้ใช้ผ่าน HTML5 Geolocation API
  - ระบบขออนุมัติพิกัดหมุด (Pending Approval) โดยผู้ดูแลระบบ
- **ตลาดซื้อขายแคน & เครื่องดนตรีอีสาน (Marketplace):**
  - แสดงผลในรูปแบบ Responsive Grid พร้อมราคา คีย์เสียง สเปกไม้กู่แคน ลิ้นแคน และมาตรฐานเทียบเสียง 440Hz
  - ระบบแกลเลอรีภาพถ่ายสินค้าจริงหลายมุมมอง (สูงสุด 5 รูป)
  - ป้ายสถานะสินค้า (พร้อมจำหน่าย / สินค้าหมด Sold Out)
- **ระบบโปรไฟล์และแกลเลอรีผลงาน (Profile & Showcase):**
  - อัปโหลด **ภาพถ่ายผลงานจริงและบรรยากาศศูนย์ทำแคน** (สูงสุด 6 รูป พร้อมระบบ Lightbox ซูมดูภาพขนาดใหญ่)
  - ระบบรีวิว ให้คะแนนดาว (1-5 ดาว) และข้อคิดเห็นจากผู้ใช้งานจริง
  - ระบบจัดการสินค้าของตนเอง (ปรับเป็นสินค้าหมด, ปิดประกาศนำออกจากตลาด, แก้ไขข้อมูลสินค้า)
